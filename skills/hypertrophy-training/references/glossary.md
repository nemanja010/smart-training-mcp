# Hypertrophy Training Glossary

## Training Terms

| Term | Definition |
|------|------------|
| **1RM** | One-Rep Maximum - the maximum weight you can lift for one repetition |
| **BFR** | Blood Flow Restriction - using cuffs to restrict blood flow during training |
| **Compound movement** | Exercise using multiple joints (squat, deadlift, bench press) |
| **Concentric** | Muscle-shortening phase of a lift (lifting the weight) |
| **Deload** | Planned reduction in training volume/intensity for recovery |
| **DUP** | Daily Undulating Periodization - varying intensity each session |
| **Eccentric** | Muscle-lengthening phase (lowering the weight) |
| **Failure** | Point where another rep is impossible with good form |
| **Isolation** | Exercise using one joint (curl, extension, fly) |
| **Lengthened partials** | Training in the stretched position (bottom ROM) |
| **Mesocycle** | 4-6 week training block with specific goals |
| **Microcycle** | Typically one week of training |
| **Progressive overload** | Gradually increasing training demands over time |
| **RIR** | Reps In Reserve - how many reps you could still do |
| **ROM** | Range of Motion |
| **RPE** | Rate of Perceived Exertion (6-10 scale) |
| **SFR** | Stimulus-to-Fatigue Ratio |
| **Split** | How training is divided across the week |
| **TUT** | Time Under Tension |

## Volume Terms

| Term | Definition |
|------|------------|
| **MEV** | Minimum Effective Volume - lowest volume for growth |
| **MAV** | Maximum Adaptive Volume - optimal volume range |
| **MRV** | Maximum Recoverable Volume - most you can recover from |
| **Working set** | Set performed at target intensity (not warm-up) |
| **Tonnage** | Total weight lifted (sets × reps × weight) |

> **Detailed volume landmarks by muscle group:** See SKILL.md Section 1.2

## Physiology Terms

| Term | Definition |
|------|------------|
| **Hypertrophy** | Increase in muscle size |
| **MPS** | Muscle Protein Synthesis - process of building muscle protein |
| **MPB** | Muscle Protein Breakdown |
| **mTOR** | Molecular pathway that regulates protein synthesis |
| **Satellite cells** | Muscle stem cells that contribute to growth |
| **Type I fibers** | Slow-twitch, endurance-oriented muscle fibers |
| **Type II fibers** | Fast-twitch, strength/power-oriented muscle fibers |
| **Anabolic** | State of building/growth |
| **Catabolic** | State of breakdown |
| **DOMS** | Delayed Onset Muscle Soreness |

## Nutrition Terms

| Term | Definition |
|------|------------|
| **BMR** | Basal Metabolic Rate - calories burned at rest |
| **TDEE** | Total Daily Energy Expenditure - total daily calories |
| **DIAAS** | Digestible Indispensable Amino Acid Score - protein quality measure |
| **Leucine** | Key amino acid for triggering MPS |
| **EAA** | Essential Amino Acids - must come from diet |
| **BCAA** | Branched-Chain Amino Acids (leucine, isoleucine, valine) |
| **Surplus** | Eating above maintenance calories |
| **Deficit** | Eating below maintenance calories |
| **Recomp** | Body recomposition - gaining muscle while losing fat |
