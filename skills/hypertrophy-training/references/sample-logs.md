## Log Format Guide

### Essential Fields

| Field | Description | Example |
|-------|-------------|---------|
| Date | Workout date | 2026-02-01 |
| Workout | Session name | Push A |
| Body Weight | Morning weight | 82.3 kg |
| Sleep | Hours + quality | 7.5h (8/10) |
| Energy | Pre-workout energy | 7/10 |
| Exercise | Movement name | Bench Press |
| Sets × Reps | Work performed | 4 × 8, 8, 7, 6 |
| Weight | Load used | 100 kg |
| RIR | Reps in reserve | 2, 1, 1, 0 |
| Notes | Observations | Left tricep fatigued |
