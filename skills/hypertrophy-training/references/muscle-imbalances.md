## Types of Imbalances

### Bilateral Asymmetry

**Definition:** Strength or size difference between left and right sides

| Severity | Difference | Action |
|----------|------------|--------|
| Normal | <10% | No intervention needed |
| Mild | 10-15% | Unilateral work, lead with weak side |
| Moderate | 15-25% | Dedicated correction protocol |
| Severe | >25% | Consider professional assessment |

### Agonist-Antagonist Imbalance

**Definition:** Ratio between opposing muscle groups outside optimal range

| Muscle Pair | Optimal Ratio | Common Problem |
|-------------|---------------|----------------|
| Hamstrings : Quads | 0.6-0.8 : 1 | Weak hamstrings |
| Rear delts : Front delts | 1 : 1 | Weak rear delts |
| External : Internal rotators | 0.7-0.8 : 1 | Weak external rotators |
| Pulling : Pushing | 1-1.5 : 1 | Insufficient pulling |
| Hip extensors : Hip flexors | 1 : 1 | Weak/tight hip flexors |

### Postural Imbalances

| Pattern | Tight Muscles | Weak Muscles |
|---------|---------------|--------------|
| **Upper Crossed** | Pecs, upper traps, levator scapulae | Deep neck flexors, lower traps, serratus |
| **Lower Crossed** | Hip flexors, lumbar erectors | Glutes, abs |
| **Rounded Shoulders** | Pecs, anterior delts | Rhomboids, rear delts, mid traps |

## Assessment Methods

### Visual Assessment

1. **Front view:** Shoulder height, hip alignment, arm hang
2. **Side view:** Head position, shoulder rounding, pelvic tilt
3. **Back view:** Scapular position, spinal alignment

### Functional Tests

| Test | What It Reveals | Ideal Result |
|------|-----------------|--------------|
| Overhead squat | Hip, ankle, thoracic mobility | Arms stay vertical, no knee cave |
| Single-leg squat | Unilateral strength, hip control | Knee tracks over toe, no trunk lean |
| Wall angel | Thoracic extension, shoulder mobility | Full contact with wall throughout |
| Thomas test | Hip flexor tightness | Thigh rests on table, knee at 90° |

### Strength Testing

**Unilateral testing protocol:**
1. Test dominant side first
2. Record max weight or reps
3. Test non-dominant side with same load
4. Calculate percentage difference

```
Asymmetry % = ((Strong - Weak) / Strong) × 100
```

## Common Imbalance Patterns

### Desk Worker Pattern

**Characteristics:**
- Rounded shoulders
- Forward head posture
- Tight hip flexors
- Weak glutes

**Priority corrections:**
1. Hip flexor stretching + glute activation
2. Thoracic extension work
3. Face pulls and rear delt work
4. Deep neck flexor strengthening

### Bench Press Bro Pattern

**Characteristics:**
- Overdeveloped front delts and pecs
- Underdeveloped rear delts and back
- Internal rotation dominance
- Rounded shoulders

**Priority corrections:**
1. 2:1 or 3:1 pulling to pushing ratio
2. Face pulls every workout
3. Rear delt isolation
4. Reduce pressing volume temporarily

### Quad-Dominant Pattern

**Characteristics:**
- Strong quads, weak hamstrings
- Hip flexor tightness
- Poor hip hinge mechanics
- Potential knee issues

**Priority corrections:**
1. RDL and hip hinge emphasis
2. Seated leg curl prioritization
3. Glute bridges and hip thrusts
4. Hip flexor stretching

## Correction Strategies

### Unilateral Training Approach

**Rule:** Always start with the weaker side

**Protocol:**
1. Perform exercise with weak side first
2. Match volume on strong side (don't exceed weak side)
3. Use same weight for both sides
4. Add extra set for weak side only (optional)

### Volume Adjustment

| Imbalance Type | Weak Side Volume | Strong Side Volume |
|----------------|------------------|-------------------|
| Mild (<15%) | Normal | Normal |
| Moderate (15-25%) | Normal + 2 sets | Normal |
| Severe (>25%) | Normal + 4 sets | Normal - 2 sets |

### Exercise Sequencing

**Prioritize corrections early in workout:**
1. Weak point exercises first (freshest)
2. Unilateral before bilateral
3. Antagonist work before agonist for imbalanced pairs

## Programming for Correction

### 8-Week Correction Protocol

**Weeks 1-4: Assessment & Foundation**
- Test all bilateral asymmetries
- Include 2-3 unilateral exercises per session
- Lead with weak side always
- Track reps/weight differences

**Weeks 5-8: Targeted Correction**
- Add extra volume for weak side (1-2 sets)
- Include specific weakness exercises
- Re-test at week 8
- Continue if >10% asymmetry remains

### Sample Correction Workout (Upper Body)

```
1. Single-arm DB row (weak side first): 4×10 each
2. Single-arm cable press: 3×12 each
3. Face pulls: 3×15
4. Single-arm lateral raise: 3×12 each (extra set weak side)
5. Single-arm curl: 3×10 each
6. Single-arm pushdown: 3×12 each
```

## When to Seek Professional Help

- Asymmetry doesn't improve after 8 weeks
- Pain associated with imbalance
- Asymmetry >30%
- Visible structural differences
- Post-injury imbalances

**Professionals to consult:**
- Physical therapist (movement, pain)
- Sports medicine doctor (structural)
- Qualified strength coach (programming)
